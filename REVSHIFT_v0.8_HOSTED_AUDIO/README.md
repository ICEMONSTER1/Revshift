# REV//SHIFT v0.8 — XPENG Cockpit / Hosted Real Sound

เว็บจำลองหน้าปัดเรือนไมล์พร้อมเสียงบันทึกเครื่องยนต์จากรถจริงสำหรับจอรถ XPENG G6 / X9 และรถที่มี Browser รองรับเสียง MP3

## แก้ตรงไหนจาก v0.7
- เว็บ **ไม่** โหลดไฟล์เสียงสดจาก Wikimedia ทุกครั้งที่กด START อีกแล้ว
- ตอนสร้าง/เผยแพร่เว็บ GitHub Actions จะดาวน์โหลดเสียง CC ที่มีใบอนุญาต ชุดไฟล์จริง แล้วแปลงเป็น MP3 รองรับ Safari/iPhone
- จะปรากฏเฉพาะรุ่นที่ไฟล์เสียงได้รับและตรวจสอบแล้วเท่านั้น; ถ้าดึงไฟล์ไม่ได้ทุกคัน การสร้างเว็บจะล้มเหลวแทนที่จะสร้างเว็บเงียบ ๆ
- ผู้เปิดเว็บบนรถเลือกแบรนด์/รุ่น → START SOUND ได้เลย ไม่ต้องอัปโหลดหรือดาวน์โหลดไฟล์เอง
- หลังเผยแพร่ MP3 ถูกเสิร์ฟจาก **โดเมนเดียวกับเว็บ**; ไม่มี CORS hotlink / ลิงก์เสียงปลอมที่ส่ง HTML แทน MP3

## นำขึ้นเว็บ HTTPS ฟรี — GitHub Pages
1. เข้าสู่ระบบ GitHub และสร้าง repository (เช่น `revshift-cockpit`)
2. อัปโหลดไฟล์/โฟลเดอร์ **ทั้งหมด** ของโปรเจกต์นี้ลง root (รวม `.github/workflows/deploy.yml`)
3. Settings → Pages → Build and deployment → Source: **GitHub Actions**
4. แท็บ Actions → เลือก workflow "Build real engine sound website" → Run workflow ถ้า workflow ยังไม่ทำงานจาก push
5. เมื่อ build สำเร็จ เปิด URL ที่ Pages แสดง เช่น `https://<username>.github.io/revshift-cockpit/` บนจอ XPENG
6. เลือกแบรนด์/รุ่น → START SOUND ให้สิทธิ์เล่นเสียงตามข้อกำหนดของ Browser; เช็กเสียงจากลำโพงรถ

**คุณไม่จำเป็นต้องดาวน์โหลดไฟล์เสียงบน iPhone/จอรถเลย**: MP3 อยู่บนโฮสต์เว็บแล้ว

ถ้า workflow ไม่สำเร็จ ให้ดู log ใต้คำว่า `SKIPPED:`; อาจเกิดเพราะ Wikimedia จำกัดการดาวน์โหลด/ระบบเครือข่าย/แปลงไฟล์ ในกรณีนี้ *ไม่มีการสร้างเว็บที่แสร้งว่ามีเสียง*

## ทดสอบจากคอม
รัน `python scripts/build_site.py` (ต้องมีอินเทอร์เน็ต; ควรมี ffmpeg ใน PATH), แล้วรัน `python -m http.server 8000 --directory dist` และเปิด http://localhost:8000

## ข้อจำกัดที่ยังไม่ใช่เวอร์ชันสมบูรณ์
- เพลง/คลิปเสียงที่ได้เป็น **real field recordings** ไม่ใช่ multi-RPM multi-load Sound Bank; การจำลอง RPM และเกียร์เป็นข้อมูลคำนวณ, ไม่มีคลิป Rev-match จริงในชุดนี้ จึงยัง **ไม่สมจริงเท่า TesRev**
- ตัวเว็บไซต์บน **GitHub Pages เป็น static** ไม่มี WebSocket relay จึงยังใช้ QR PHONE SYNC ระหว่าง iPhone กับจอรถไม่ได้ แม้ UI เดิมอาจยังแสดงตัวเลือก; ต้องมี backend HTTPS/WSS เพื่อส่งข้อมูล GPS/Motion ระหว่างเครื่อง
- GPS บนจอ XPENG มีข้อจำกัดขึ้นกับเบราว์เซอร์และเฟิร์มแวร์; หากไม่รองรับ ใช้ DEMO ทดสอบก่อน
- ไม่อ่านแป้นคันเร่งจริงจาก XPENG; ความเร็วและการเร่งเป็น GPS/ประมาณค่า
- ไฟล์เสียงเหล่านี้ฟรีแบบมีเงื่อนไข Creative Commons; ไม่ได้เป็นเสียงจาก Stock/Tuned ครบทุกแบบ 
- ตั้งค่าและทดสอบเมื่อรถจอดเท่านั้น ตรวจสอบว่าลำโพงไม่กลบเสียงเตือนด้านความปลอดภัย

ระบบสร้างไฟล์ในสภาพแวดล้อมการสนทนานี้ไม่สามารถเชื่อมต่อไปยังโฮสต์เก็บเสียงเพื่อดาวน์โหลดไบนารีได้จริง จึงไม่อ้างว่าแพ็กเสียงอยู่ใน ZIP. **GitHub Actions ดาวน์โหลดและแพ็กเสียงจากเว็บต้นทางให้โดยอัตโนมัติบนเซิร์ฟเวอร์ตอน Deploy** (การ deploy ต้องทำจากบัญชี GitHub ของคุณ)
